# Meridian Hospital – SQL Project

## 📌 Project Overview

This project is a SQL-based hospital data analysis project using a fictional hospital dataset.

The project analyzes patients, doctors, appointments, departments, medical records, prescriptions, medicines, billing, staff, and rooms.

## 🎯 Objectives

* Analyze hospital patient data
* Identify doctors with the most appointments
* Analyze appointment trends
* Analyze hospital revenue
* Practice SQL joins and aggregations
* Answer real-world business questions using SQL

## 🗂️ Database Tables

* Patients
* Doctors
* Departments
* Appointments
* Medical Records
* Prescriptions
* Medicines
* Billing
* Staff
* Rooms

## 🛠️ Tools Used

* MySQL

## 📊 Sample Questions

1. Which doctor has the most appointments?
2. Which department has the highest number of patients?
3. What is the total hospital revenue?
4. Which patients have multiple appointments?
5. What is the average billing amount?
6. Which patients have outstanding bills?
7. What are the most frequently prescribed medicines?

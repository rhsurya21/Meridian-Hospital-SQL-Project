# Meridian Hospital – SQL Project

## 📌 Project Overview

This project is a SQL-based hospital data analysis project using a fictional hospital dataset.

The project analyzes patients, doctors, appointments, departments, medical records, prescriptions, medicines, billing, staff, and rooms.

## 🎯 Objectives

* Analyze hospital patient data
* Identify doctors with the most appointments
* Analyze appointment trends
* Analyze hospital revenue
* Practice SQL joins and aggregations
* Answer real-world business questions using SQL

## 🗂️ Database Tables

* Patients
* Doctors
* Departments
* Appointments
* Medical Records
* Prescriptions
* Medicines
* Billing
* Staff
* Rooms

## 🛠️ Tools Used

* MySQL
* SQL
* CSV
* GitHub

## 🔍 SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
